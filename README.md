# Signal Desk

**A local dashboard for keeping a targeted job search organized.**

## The problem

Find the company. Check the role. Find the right contact. Draft the email. Remember whether I already applied. Repeat.

At some point, the job search itself needed a dashboard. I asked for a small, clean view of companies, applications, contact research, and what needed to happen next.

## The solution

A local job-search workspace that brings a shortlist, research queue, company information, and application context together, supported by a CV-grounded research/drafting workflow.

## What it does

- Company shortlist and queue views.
- Application and outreach context in one place.
- Company briefs and contact-research tracking.
- A local project/CV index for grounded application wording.
- A workflow that separates prepared email drafts from sending.

## Engineering highlights

Pairs a lightweight local interface with a CV-grounded project index, company research, application records, and connector-assisted draft preparation. The workspace keeps opportunity context and the next action visible throughout the search.

## Technology

Local HTML/CSS/JavaScript dashboard, Markdown workspace records, connector-assisted research and draft preparation.
